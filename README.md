# Relief Studio

Relief Studio is a Windows desktop app that turns images into printable reliefs, automatically assigns color stages, and provides controls to edit colors, heights, borders and print settings.

This repository is for development tracking only: feature status, bugs, release notes and validation. App source, build scripts, artwork, filament catalogs, executables, installers and release archives stay outside this repository. No app downloads or build artifacts are hosted here.
