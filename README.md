# Relief Studio

Relief Studio is a Windows desktop app that turns images into printable reliefs, automatically assigns color stages, and provides controls to edit colors, heights, borders and print settings.

This repository tracks features, bugs, release notes and validation. The owner has also authorized the customer Windows installer below as a GitHub Release asset. Application source, build scripts, standalone artwork/catalog data, owner tools, signing keys and private records are not published here.
