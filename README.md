# Relief Studio

Private development tracking for Relief Studio, a Windows image-to-relief application by Will Radford, inspired by Whitney Collins.

Current delivered version: **2.13.0-alpha.1**.

- [Feature tracker](FEATURES.md)
- [Release history](CHANGELOG.md)
- [Open work and ideas](https://github.com/radfordwill/relief-studio/issues)

Completed implementation issues are closed. Remaining print, installation and visual validation are tracked separately. Ideas have no committed release date.

For each development session, check existing issues before creating new ones, update progress and test evidence, and update the changelog when delivering a release. Include the app version, reproduction steps, expected and actual results when reporting bugs.

This repository currently contains tracking documents, not the app source or installer binaries. Updates are made during development sessions; there is no background synchronization. GitHub Projects board setup is not included.
